# Сброс отказов от ГОСТ TLS в Яндекс Браузере

PowerShell-скрипт для техподдержки. Если пользователь нажал «Отключить поддержку ГОСТа» и сайт перестал открываться, скрипт очищает сохранённые отказы в `tlsgost.bad_hosts`. При следующем открытии сайта браузер может снова предложить подключение по ГОСТ TLS.

## Быстрый запуск

Требуется Windows PowerShell 5.1 или новее. Откройте PowerShell в папке со скриптом **под учётной записью сотрудника**, у которого возникла проблема. Список доменов вводить не нужно.

```powershell
.\Fix-YandexGost.ps1
```

По умолчанию скрипт сбрасывает все сохранённые отказы во всех найденных профилях в стандартной папке `%LOCALAPPDATA%\Yandex\YandexBrowser\User Data`. Если браузер запущен, выйдите через `Ctrl+Shift+Q` и повторите команду.

Если сотрудник сохранил работу, браузер можно закрыть принудительно и сразу выполнить сброс:

```powershell
.\Fix-YandexGost.ps1 -ForceClose
```

`-ForceClose` завершает проверенные процессы Яндекс Браузера текущего пользователя в текущем сеансе, когда есть записи для сброса. После этого скрипт ждёт завершения процессов до 5 секунд. Принудительное закрытие может привести к потере несохранённых данных во вкладках.

После сброса откройте сайт в нужном профиле и подтвердите подключение по ГОСТ, если браузер его запросит.

## Дополнительные команды

```powershell
# Показать, в каких профилях есть записи для сброса
.\Fix-YandexGost.ps1 -WhatIf

# Сбросить только указанные хосты в одном профиле
.\Fix-YandexGost.ps1 -Profile 'Profile 1' -Site 'portal.example', 'https://service.example/login'

# Показать пути к созданным резервным копиям
.\Fix-YandexGost.ps1 -Verbose
```

`-Profile` принимает имя папки профиля, которое можно посмотреть на странице `browser://version`. `-Site` сопоставляет точные имена хостов. `-WaitSeconds` меняет время ожидания после принудительного завершения.

## Резервная копия и откат

Для каждого изменённого `Preferences` рядом создаётся отдельная копия `Preferences.gost-ГГГГММДД-ЧЧММСС-<GUID>.bak`. В имени указано локальное время клиентского ПК. Чтобы откатить сброс, полностью закройте браузер и замените `Preferences` выбранной копией. Такой откат восстанавливает все настройки профиля на момент создания копии.

`tlsgost.bad_hosts` — внутреннее поле Яндекс Браузера. Скрипт применим, когда отказ сохранён именно в этом поле.
